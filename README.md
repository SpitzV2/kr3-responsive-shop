## Доступность
- добавлена ссылка пропуска к основному содержимому (`skip-link`);
- добавлен видимый фокус `:focus-visible` с контрастной синей обводкой;
- проверены `label` у полей формы (все поля ввода имеют связанные `<label for="...">`);
- проверены `alt` у изображений (все контентные изображения имеют понятные текстовые описания);
- исправлены проблемы контрастности текста и ссылок по стандарту WCAG AA;
- модальное окно реализовано на базе нативного тега `<dialog>` с корректным перехватом фокуса и закрытием по клавише Escape;
- добавлено подчеркивание текстовых ссылок для выполнения правила `link-in-text-block`;
- выполнена проверка Lighthouse.

## Исправления доступности
- **Ссылка пропуска к контенту:** в начале страницы добавлена ссылка `.skip-link`, позволяющая пользователям клавиатуры сразу перейти к `<main id="main">`.
- **Видимый фокус:** для псевдокласса `:focus-visible` задана яркая обводка `outline: 3px solid #0057b8`, делающая перемещение по Tab наглядным.
- **Подписи полей формы:** каждому полю `<input>`, `<select>`, `<textarea>` сопоставлен соответствующий тег `<label>` через атрибуты `id` и `for`. Обязательные поля помечены `required` и `aria-required="true"`.
- **Кнопки закрытия:** кнопкам закрытия диалоговых окон добавлен атрибут `aria-label="Закрыть окно заявки"`, значок крестика скрыт через `aria-hidden="true"`.
- **Контрастность цветов:** скорректирован цвет ссылок на `#71551b` для обеспечения коэффициента контрастности более 4.5:1 на светлом фоне.
- **Ссылки в тексте:** добавлено подчеркивание ссылок в блоках текста (`text-decoration: underline`), чтобы они различались не только цветом.
- **Модальное окно:** окно открывается через `.showModal()`, возвращает фокус на вызвавший элемент при закрытии и закрывается по нажатию Escape или клику вне диалога.
